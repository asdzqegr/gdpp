# gdpp

Directly installs GDextension C++ inside any Godot Project

Uses official godot-cpp repos : https://github.com/godotengine/godot-cpp.git

Uses godot-cpp template repos for SConstruct gdextension and C++ src files : https://github.com/godotengine/godot-cpp-template


It basically installs godot-cpp and the template then compile the src files with SConstruct inside the selected game project.

Work in progress.

This project will be implemented inside a Godot plugin for better compatibility and better user experience.
